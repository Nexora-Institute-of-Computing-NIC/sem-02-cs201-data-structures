# CS201 — Data Structures — PLAN

**Semester:** 2 · **Credits:** 4 · **Level:** Beginner-Intermediate
**Theory:** 45 hrs · **Lab:** 30 hrs · **Language:** C

## Syllabus

### Unit 1 — Foundations and Arrays (9 lectures)
1. What a data structure is — the shape of data
2. Abstract Data Types (ADT) — interface vs implementation
3. Time and space complexity — Big-O notation
4. Analysing loops, nested loops, recursion
5. Static vs dynamic arrays
6. Array operations — insert, delete, search
7. Two-dimensional arrays and sparse matrices
8. String representations — fixed and dynamic
9. When arrays are the wrong choice

### Unit 2 — Linked Lists, Stacks and Queues (9 lectures)
1. Pointers and nodes — the building block of linked structures
2. Singly linked lists — traversal, insert, delete
3. Doubly linked lists — bidirectional traversal
4. Circular linked lists
5. Linked list variants — with and without dummy head
6. Stacks — LIFO, array-based and list-based
7. Applications of stacks — parentheses, postfix, undo
8. Queues — FIFO, circular array, linked implementation
9. Deques and priority queues (introduction)

### Unit 3 — Trees and Heaps (9 lectures)
1. Tree terminology — root, leaf, height, depth
2. Binary trees — representations and traversals
3. Preorder, inorder, postorder — recursive and iterative
4. Level-order traversal with a queue
5. Binary search trees — insertion, search, deletion
6. Balanced BSTs — AVL rotations
7. Heaps — min-heap and max-heap
8. Heap operations — insert, extract, build-heap
9. Heapsort and priority queue applications

### Unit 4 — Hashing, Sorting and Searching (9 lectures)
1. Hash functions — division, multiplication, universal
2. Collision resolution — chaining
3. Collision resolution — open addressing, linear probing, double hashing
4. Load factor and rehashing
5. Linear search and binary search
6. Quadratic sorting — bubble, insertion, selection
7. Efficient sorting — merge sort and quicksort
8. Non-comparison sorting — counting, radix
9. Choosing a sort — stability, memory, data shape

### Unit 5 — Graphs and Advanced Structures (9 lectures)
1. Graph terminology — vertices, edges, degree, path
2. Graph representations — adjacency matrix vs adjacency list
3. Breadth-first search and depth-first search
4. Topological sorting
5. Shortest paths — Dijkstra and Bellman-Ford
6. Minimum spanning trees — Prim and Kruskal
7. Union-Find (disjoint set) with path compression
8. Tries — prefix trees for strings
9. Segment trees and Fenwick trees (introduction)

## Practical Labs (18)

1. Implement a dynamic array with grow/shrink
2. Measure Big-O empirically — time array operations vs N
3. Singly linked list — create, insert, delete, traverse
4. Doubly linked list — reverse in place
5. Detect a cycle in a linked list (Floyd's algorithm)
6. Stack implementation and parentheses checker
7. Infix to postfix converter using a stack
8. Postfix expression evaluator
9. Circular queue implementation
10. Binary tree traversals (preorder, inorder, postorder, level-order)
11. Binary search tree — insert, search, delete
12. AVL tree rotations and balance factors
13. Min-heap and max-heap — insert, extract, heapsort
14. Hash table with chaining
15. Hash table with open addressing
16. Merge sort, quicksort, and comparison timing
17. Graph BFS and DFS
18. Dijkstra's shortest path

## Assignments

1. Complexity analysis — analyse five given algorithms in Big-O
2. Linked list — implement a full-featured list library
3. Stacks and queues — two classic applications
4. Trees — BST + traversal exercises
5. Sorting and searching comparison writeup
6. Graph algorithms — BFS, DFS, Dijkstra
